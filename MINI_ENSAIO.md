Next.js
- O que é: Framework para apps web usando React. 
- Para que serve: Facilita páginas rápidas e amigáveis para busca (SEO) e deploy.
- Quando usar: Projetos front-end interativos que precisam rodar online fácil (Vercel).

Django
- O que é: Framework Python completo para construir sites e painéis administrativos.
- Para que serve: Rápido para aplicativos que precisam de autenticação, admin e regras de negócio.
- Quando usar: Apps com backend pesado e lógica complexa.

FastAPI
- O que é: Framework Python moderno para criar APIs rápidas.
- Para que serve: Facilitar criação de endpoints (rotas) que o frontend chama.
- Quando usar: Backends que precisam ser rápidos e bem documentados.

Inversão de Controle (IoC)
- O que é: Padrão onde a criação e provisão de dependências é delegada a um controlador externo.
- Por que importa: Deixa o código mais organizado e fácil de testar.

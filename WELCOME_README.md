Bem-vindo
=========

Coloque a imagem desejada de boas-vindas com o nome `welcome.jpg` na raiz do projeto (mesmo diretório de `index.html`).

Após login bem-sucedido, o frontend redirecionará para `welcome.html` que exibe `welcome.jpg` em tela cheia.

Se preferir outro nome de arquivo, atualize o `src` em `welcome.html`.
